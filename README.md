# Код города · МГТС · ИИ-дашборд программы стажировок

Кейс-чемпионат МГТС, направление 2 — «ИИ в бизнес-процессах». Нужен
интеллектуальный аналитический дашборд для мониторинга шестимесячной программы
стажировок: собирает ежемесячные опросы стажёров и наставников, анализирует оценки
и свободные комментарии, отслеживает динамику, подсвечивает проблемы и показывает
сводку по каждому стажёру.

Этот репозиторий — вся подготовка: разбор рынка, исследование данных, рабочая
часть ИИ-слоя, план работ и протоколы внутренних споров, из которых выросли решения.

## Что важно знать про формат

- **На финале три часа на разработку.** 26 ноября, очно, 9:00–18:00.
  Значит цель подготовки — не «демо через неделю», а заготовка, которая за три
  часа принимает чужие файлы.
- **Данные — выгрузки Excel и Word**, анонимизированные ID. API нет.
- **Вопросы в опросах одинаковые каждый месяц** — динамика по месяцам считается
  честно, серии сравнимы.
- Квалификационное задание — до **19 ноября**, финалисты — **23 ноября**.

Подробно, с таймкодами записи брифинга: `docs/briefing-notes.md`.

## Идея в трёх пунктах

1. **Парный опрос стажёр ↔ наставник.** У них разные анкеты про одного человека.
   Расхождение между двумя оптиками — сам по себе сигнал, и его не считает никто
   из игроков рынка.
2. **Риск с объяснением, а не со скором.** Детерминированные флаги с порогами,
   названными до просмотра результата, плюс цитата из ответа. Никакой «модели»,
   которая на сорока стажёрах предсказывает ничего.
3. **Проверка качества данных.** Односложные ответы, одинаковые оценки всей группе,
   пропавшая обратная связь. Система контролирует вход и честно говорит «сигнала
   нет» вместо выдуманной проблемы.
